# E4：收敛—时间剖面诊断（开发集，只读）

> 状态：**修订版 v2，待审阅**（未写入主研究进展文档；未修改任何源码/配置/评价脚本；
> 未重跑或覆盖任何既有结果）。日期：2026-09-03；分支：`ppp-varerr-model`。

## 1. 口径与边界

- 数据：仅三组开发集（2021-07-14 XiaomiMi8、2021-12-08 XiaomiMi8、
  2021-07-14 SamsungGalaxyS20Ultra）。
- 方案：SPP、A、B、C（既有 `.pos`，未重新运行）。
- PPP(A/B/C)：只取 Q=6，过滤先于时间匹配与插值；SPP 配置本身输出 Q=5 单点解，
  按既有评价口径使用其 Q5 行。
- 时间对齐：GPST−18 s 转 UTC，与 `ground_truth.csv` UnixTimeMillis 匹配（≤500 ms）。
- 轨迹起点 T0 = 第一个真值时间戳；**首个有效解 = 首个成功匹配真值的解历元**。
- 分段：0–60、60–180、180–300、300+s（后文称“轨迹后段”，不称“稳态”——
  Xiaomi 模糊度反复重置（slip=100%），后段未必真正收敛）。
- 每历元观测构成：解卫星数取 `.pos` 的 ns 列；stat 星数/vsat/slip/码残差行数取自
  `.pos.stat` 的 `$SAT`。**ns 语义已由源码确认**：PPP 解的 ns = 首个 IF 槽位上
  vsat=1（相位有效）的卫星数（SPP 的 ns 为其解算所用卫星数，含码观测）。
- 阈值进入时间**两项独立计算、分别输出**：
  - `sustained60` = 首个连续 ≥60 s 低于阈值的区间起点（**主要解释指标**）；
  - `persist` = 首个其后所有解均低于阈值的历元（**仅作“严格尾段稳定性”参考，
    不是标准收敛时间**，对零星大异常敏感）；
  - 各自未达成时分别记“未达成”。
- 中断定义：解行时间间隔 >2 s；异常定义：误差 >50 m。
- A/B/C 比较（B−A 差距、异常贡献）**只使用三方案共同匹配(Q6)历元
  common_abc = A∩B∩C**；窗口共同统计同样限定在 common_abc；
  B−A 异常贡献**只按 A、B 是否 >50 m 判定**，不混入 SPP/C。
- 复现命令（脚本 `util/gsdc2022/analyze_convergence_profile.py`，只读解析现有
  文件；输出重定向即可）：

```powershell
python util\gsdc2022\analyze_convergence_profile.py > e4_out.txt
```

## 3. 跨轨迹观察（开发集探索性）

1. **PPP 在后段（300+）也不如 SPP，且不能排除全程未真正收敛**：SPP 各窗口
   P50≈2.6–4.6 m、P95 早期窗口 5.6–12.9 m、后段 6.1–7.4 m（另有一次 344 m@
   518 s 异常）；最佳 PPP（B）后段 P50 5.3–6.7 m、P95 14–22 m。Xiaomi 模糊度
   反复重置（slip=100%），本报告不把“后段”称为稳态；
2. **收敛幅度有限**：B 的 P50 从 0–60 s 的 6.6–9.9 m 降到 300+ 的 5.3–6.7 m，
   大部分在头 1–3 min；sustained60 进入 10 m 约需 186–306 s（Xiaomi MTV/LAX）
   或 ~298 s（Samsung），5 m 基本到不了（B）或从未（A）；
3. **B 相对 A 的改善并非仅由 >50 m 极端异常驱动**：剔除 A/B 任一 >50 m 的共同
   历元后 B 仍优于 A（2.65 / 3.57 / 6.48 m，异常贡献仅 4%/1%/17%），且各窗口
   P50/P95 均更低；
4. **PPP 解的相位有效星数（ns≈5–7）远少于 SPP 解算星数（13–16）**：ns 语义
   已由源码确认为首个 IF 槽位 vsat=1 的相位有效星数。stat 星数约 8.5–15.9 颗
   （12-08 Xiaomi 8.5–10.1、07-14 Xiaomi 12.9–14.3、Samsung 15.2–15.9），其中
   相位有效的仅 ~5–7 颗；GPS 与 Galileo 各自贡献多少有效相位星**尚未按系统
   统计，本报告不下系统归因结论**；
5. **中断数量不能单独解释后段误差差异**：Samsung 中断最多（19–22 个、最长
   22 s）但 B 后段仍 ~6.7 m；Xiaomi 中断少但后段同样受限。中断与模糊度重收敛
   的独立影响尚未单独量化；
6. **异常分布**：A 每轨 8–21 个 >50 m 历元（分布于全程，首个 87–231 s）；B 基本
   清除（07-14 Xiaomi 末段 ~1173 s 处残留 6 个 ~59 m；12-08 Xiaomi 仅 1 个
   @~509 s；Samsung 0）；SPP 零星（12-08 有 3 个，含 344 m@518 s）。

## 4. 对后续方向的启示（供设计参考，未形成结论）

- 浮点 PPP 后段地板约 P50 5–7 m / P95 14–22 m，且解的实际相位有效星仅 ~5–7 颗；
  **已测试的 A/B/C 及 E1 定权方案均未突破这一误差水平**；
  仅靠加权（B 已接近“弃码”）可能不足以突破，需要先按系统拆分每历元有效相位星数、
  评估几何缺口；
- 候选方向与证据对应：增加有效相位观测（**E3 解耦可用于检验能否恢复部分 Galileo
  有效相位；可恢复比例及其精度影响尚待实验**；GPS L5 属原始缺测不可补）→ 提高
  几何；用历元间约束/平滑（TDCP/后向，P4/P5）压低 P95 长尾与漂移；
  另有一条候选假设：**“码做绝对锚、相位做相对增强”（对应优胜方案思路，不含
  CORS）——该假设尚未经实验验证，仅作候选方向，不是已获数据结论**；
- 以上仅作路线参考，未写入主研究进展，未触发任何改码。

## 5. 局限

- SPP 无 `.pos.stat`，其每历元 vsat/slip/残差构成为 N/A；
- persist 是严格尾段稳定性参考（对零星异常敏感），解释以窗口与 sustained60 为主；
- GPS/Galileo 有效相位星数拆分尚未统计（见 §4），不据此下系统归因结论；
- 中断/重收敛的影响尚未独立量化（见 §3.5）；
- 全部为开发集结果，属探索性；内部留出集与 Pixel 未参与本轮。
