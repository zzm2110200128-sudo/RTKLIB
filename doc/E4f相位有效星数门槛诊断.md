## 1. 目的与口径（仅诊断）

- 检查排除"**有效相位星数较少**"（ns<5，即 ns=4 及以下）的历元后，
  A/B/C 的分窗精度是否变化，回答：E4 观察到的后段地板是否主要由这类
  历元造成；
- 术语说明：ns<5 只表示**有效相位星数较少**，不直接称"弱几何"——几何
  强弱还取决于卫星在天空的分布，需 PDOP 判断（后续 E4g 方向）；
- 口径：三方案**共同 Q6 历元**（A∩B∩C 的匹配历元）；子集 = 共同历元中
  三方案 ns 均 ≥5（E4a 已证共同历元上 A/B/C 相位有效星集一致）；
- 窗口：0–60 / 60–180 / 180–300 / 300+s（相对轨迹起点=第一个真值）；
- **约束**：本筛选只作诊断；不替代完整时间轴主指标；不据筛选后的结果
  宣称模型改进；结果与输出解的内部指标（ns）相关，存在选择效应。

## 3. 结论（本诊断范围）

- 去掉 ns=4 历元主要**减少部分窗口的 P95 长尾**（如 12-08 Xiaomi 60–180 的
  B P95 22.39→16.90、A P95 39.2→34.2；Samsung 若干窗口 P95 下降）；
- 但**稳态（300+）P50/P95 仍明显高于 SPP**（ns≥5 子集下 B P50 5.1–6.4 m、
  P95 13–22 m；SPP 稳态 P50 约 2.6–3.5 m、P95 不超过约 7 m）→ **稳态误差
  地板不是主要由 ns=4 历元造成**；
- 方案排序不变（B≈C > A）；本报告不构成任何模型改进声明。
