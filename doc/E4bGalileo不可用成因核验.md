## 1. 目的、口径与分类

目的：把 Galileo vsat=0 拆成因，并**按 RINEX E1/E5 相位 LLI 位**判断 E3
是否存在可沿用旧 bias 的连续性候选。

输入（只读）：A 方案残差 CSV（vsat、resc、phase_bias_m、phase_bias_variance、
槽位 0 slip 作对照）+ RINEX 3 逐 (E, 星, 历元) 的 E1/E5 相位/伪距存在性与
相位 LLI。`$SAT` 卫星状态行 ≠ RINEX 原始观测行，slip 判定以 RINEX 相位 LLI
为准（IFLC 下 `$SAT` 只输出槽位 0，不覆盖配对频率 E5）。

LLI 位语义（RINEX 3）：
- **bit0 = loss-of-lock 位**：只表示接收机/转换标记的失锁信号，
  **不声称已证明具体的整周周跳**；
- bit1 = half-cycle 位：半周模糊度未解决标志（按项目规则 10，不得直接视为
  真实整周周跳）。

bias 建立定义（与脚本一致）：`|phase_bias_m| > 1e-9` 或
`phase_bias_variance > 1e-12`。

分类（仅 Galileo vsat=0 行）：

| 类别 | 判据 | 含义 |
|---|---|---|
| 1 缺双频相位 | E1 或 E5 相位缺失 | Lc 组不成（数据层） |
| 2 残差被拒 | 相位齐且 resc≠0 | 进入残差后被拒（QC 范畴） |
| 3a bias 未建·码齐 | 相位齐、resc=0、bias 未建、码齐 | 本应可 reseed（异常） |
| 3b bias 未建·缺码 | 同上但至少一频伪距缺 | 无法以 Lc−Pc 建 bias |
| **4a 无任何 LLI** | 相位齐、bias 已建、缺码、E1/E5 LLI 均为 0 | 连续性候选（可尝试沿用旧 bias） |
| **4b 含 loss-of-lock 位** | 同上，但 E1 或 E5 含 bit0 | “失效”：连续性上不再可信，不代表当前源码已将 rtk->x 中的旧 bias 清零 |
| **4c 仅 half-cycle 位** | 同上，无 bit0、但 E1 或 E5 含 bit1 | 基线标记 slip 但缺码跳过重建（旧值未清零）；研究口径待核验 |
| 5 其它待查 | 相位齐、bias 在、码齐仍 vsat=0 | 未知机制 |

“4a+4b+4c”合计 = **未考虑周跳判定前的粗候选**，不是可恢复结果。

## 3. 两种口径的分开陈述

**口径一（当前 RTKLIB 基线行为）**：`detslp` 对 bit0 与 bit1 都按 slip 处理
（LLI_SLIP 与 LLI_HALFC 均触发模糊度重置），因此：
- 4a（无任何 LLI 的连续性候选）= **0**（3 组全部）；
- 4b（367/683/14）与 4c（0/0/1354）在基线下均被标记为 slip；但因缺码导致
  **Lc、Pc 均无法形成**，`udbias_ppp()` 得不到新的 bias 初值（bias[i]=0）并
  跳过重建。旧 bias 数值**可能仍留在状态向量 rtk->x 中**（并未真正清零），
  只是当前 `corr_meas()` 同时令 Lc=0，因此该相位不会进入 `ppp_res()`。
  → 基线口径下可直接沿用旧 bias 的候选为 0；**若 E3 单独恢复 Lc，必须额外
  使不可信的旧 bias 失效（清零/标记不可用），避免旧 bias 被重新用于当前相位**。

**口径二（研究解释口径，规则 10）**：bit1（half-cycle）不得直接当作真实整周
周跳，因此：
- 4c（Samsung 1354 行，E5 半周位 1354、E1 半周位 511、均无 loss 位）的
  旧 bias 是否失效**不能仅凭 LLI 判定**，仍需 ADR / Doppler / GF / MW /
  时间连续性等核验后才能确认其中哪些行可作连续性候选；
- 4b 含 loss-of-lock 位（bit0），但其是否对应真实整周周跳同样需上述交叉
  核验（bit0 只是失锁标记）；
- 两条 Xiaomi 无 4c（其类 4 行 E5 均带 bit0）。

## 4. 关于 "845 行" 的删除说明

此前 v2 提到的 “Samsung ~845 行（无 E1 标志）” **不作为主要候选数量**：
845 只是 “无 E1 标志”的保守子集；v3 中 Samsung 的全部 half-only 行为
**4c = 1354 行**（其中 E1 半周位 511 行也包含在内），应以 1354 作为待核验
对象，而非 845。

## 5. 若实施 E3，补丁设计必须满足的约束（供设计，未实现）

1. `corr_meas()` 可分别形成 `Lc` 与 `Pc`：`Lc` 只依赖两频相位，
   `Pc` 只依赖两频伪距，互不阻塞；
2. `udbias_ppp()` 仅在 `Lc`、`Pc` **同时有效**时才允许 `bias = Lc − Pc`
   初始化/重建；
3. 若检测到任一组合频率 loss-of-lock（bit0）且 `Pc` 缺失 → 旧 bias 失效
   （清零/标记不可用），不得用旧 bias 把相位送入 `ppp_res`；
4. bit1（half-cycle）是否使旧 bias 失效：基线口径视为失效；研究口径需先
   完成 §3 口径二的核验再定，**不能直接在补丁里假设**；
5. E3 的实际可恢复量以实验为准（按基线口径 4a=0，预期直接收益有限；
   研究口径的潜在对象是 Samsung 4c=1354 行，待核验）。
