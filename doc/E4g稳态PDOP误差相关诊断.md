## 1. 口径（按项目指定）

- 只读 A 的 `.pos.stat`（`$SAT`）取 vsat=1 卫星 az/el；不读星历；
- 分析集：A/B/C 三方案误差齐全的共同 Q6 历元 ∩ A `.stat` 存在历元 ∩ 稳态
  300+s；**每历元校验 $SAT vsat=1 计数 == A `.pos` ns（全部通过）**；
- 视线（ENU）：eE=cos(el)sin(az)、eN=cos(el)cos(az)、eU=sin(el)；
  设计矩阵（与代码一致）：
  - 单钟差（参考）：行 `[-eE, -eN, -eU, 1]`（≥4 星）；
  - 双系统钟差（主）：GPS `[-eE, -eN, -eU, 1, 0]`、GAL `[-eE, -eN, -eU, 1, 1]`
    （≥5 星且 rank=5）；每个历元增加一个 **Galileo 相对 GPS 的钟差未知量**，
    **不建模、也不假设该钟差在时间上恒定**；
- numpy SVD 求秩、条件数与 PDOP=√(trace((HᵀH)⁻¹[0:3,0:3]))；
- 不满秩/星数不足 = 不可计算，单独报告（不删除）；不加 C/N0/高度角权重；
- **单钟差与双钟差在“同一批双钟差可计算历元”上比较**，并校验
  dual ≥ single（违反数报告）；
- PDOP 四分位边界按本轨迹全部可计算共同稳态历元统一计算，A/B/C 共用；
  另加 **PDOP ≥ P95（最高约 5%）子集**统计，不与四分位（最高 25%）混用；
- Spearman 平均秩（处理并列），报告 n；ns 分组 n<20 标"样本不足"；只报
  描述性 ρ，不做独立样本显著性（时间序列自相关）。

## 3. 事实性观察（描述性，非因果、非模型结论）

1. **PDOP–稳态误差总体 ρ 接近 0 且符号随轨迹/分组变化**（−0.10 ~ +0.14）：
   单历元瞬时几何 PDOP 与稳态误差无明显单调关系；
2. **固定 ns 后 ρ 多为负或弱**（07-14 Xiaomi ns=5 −0.45~−0.52、Samsung ≥8
   −0.33~−0.42、12-08 ns=7 +0.23~+0.30）：星数固定时关联同样不稳定；
3. **最高约 5% PDOP 历元未表现出更高的误差 P95**；12-08 Xiaomi 的 B/C
   P50 略高（5.02→6.64/6.67 m），其余轨迹该子集误差甚至更低（描述性）——
   不能笼统写“PDOP 尾部并不对应大误差”，应表述为该子集 P95 不更高、
   B/C P50 略高；
4. **不可计算（秩不足/仅单系统/低 ns）历元的误差 P50/P95 在描述性统计上
   较高**（未做显著性检验），且含“仅单系统”时段；
5. 双钟差 PDOP ≥ 单钟差 PDOP 在可算历元上全部成立（violation=0）。

## 4. 结论（本诊断范围）

在双系统钟差模型可计算的共同稳态历元内，**未检测到瞬时、未加权 PDOP 与
水平误差之间稳定的正向单调关系**。因此，这部分稳态误差地板**不能由有效
相位星的瞬时空间分布单独解释**。但秩不足、仅单系统及低有效星数历元的误差
描述性统计更高，说明**不能进一步概括为“几何无影响”**。

## 5. 局限

- PDOP 为单历元瞬时几何指标，PPP 为带历史状态滤波 → 仅描述性相关，不证明
  因果；不替代完整时间轴主指标；
- 双系统钟差模型：每历元增加一个 Galileo 相对 GPS 的钟差未知量，不建模、
  不假设其在时间上恒定；
- 不可计算/分组比较未做显著性检验；
- 仅开发集 3 组、稳态 300+s；未读内部留出集与 Pixel。
