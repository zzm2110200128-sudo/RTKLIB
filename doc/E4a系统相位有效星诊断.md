## 1. 口径与边界

- 数据：仅三组开发集（07-14 XiaomiMi8、12-08 XiaomiMi8、07-14 SamsungGalaxyS20Ultra）；
  不读取内部留出集与 Pixel。
- 输入：既有 A/B/C 的 `.pos.stat`（`$SAT`）与 `.pos`（Q=6 行 ns 列）、
  `ground_truth.csv`（仅取起点时间戳）；只读，不重跑解算。
- 系统拆分按卫星编号首字母：GPS=G、Galileo=E（配置 navsys=GPS+Galileo）。
- 每历元指标：G/E 的 `$SAT` **卫星状态行**数、G/E 的 vsat=1 有效相位星数、
  总有效相位星 tot_v1 = G_v1 + E_v1。
  注：`$SAT` 卫星状态行是 RTKLIB PPP stat 输出中的卫星状态行（每星每历元
  一条），**不等于 RINEX 原始相位观测行**，不含逐频观测构成。
- ns 核对分三项输出：`.stat` 有而 `.pos` Q6 无（stat_only）、`.pos` Q6 有而
  `.stat` 无（pos_only）、共同历元上 tot_v1 ≠ ns（same_epoch_mismatch）。
- 窗口：0–60 / 60–180 / 180–300 / 300+s（相对轨迹起点 = 第一个真值时间戳）。
- 历元占比：tot_v1<4、=4、5–7、≥8；G_v1=0、E_v1=0；仅 Galileo≥4、仅 GPS≥4。
- A/B/C vsat=1 集合一致性：三方案**共同历元**上逐历元比对（G、E 分别比对集合）。
- **E3 理论可恢复上限**：Galileo 有卫星状态行但 vsat=0 的历元数与行数；仅作
  **上限参考，不当作可恢复结果**（其中部分行可能连可用相位都没有，且未做
  实验验证）。
- 上限视角（仅供决策门槛参考）：tot_ub = G_v1 + E_n（假设 Galileo 全部卫星
  状态行都变为有效相位时的理论上限），同样不作结论。
- 本报告不预设“Galileo 主导”或“E3 一定有效”的结论，只列事实。

## 2. 结果

> 说明：本报告各窗口/占比表格以 **A 方案自身历元**为代表口径；A/B/C 在
> 共同历元上的相位有效星集合一致（见 2.0），但三方案总历元数略有不同
> （07-14 Xiaomi：A 1164 / B 1167 / C 1167；12-08 Xiaomi：A 1438 / B,C 1440；
> Samsung：A 1024 / B 1035 / C 1036）。未把全部窗口统计限制到共同历元，
> 因此**不声明 A/B/C 统计数字完全一致**。

### 2.0 两项一致性核验（先于系统统计）

1. **ns 核对**：三轨迹 × A/B/C 全部为 stat_only = 0、pos_only = 0、
   共同历元上 tot_v1 ≠ ns = 0 → `.stat` 与 `.pos` Q6 历元一一对应，口径自洽；
2. **A/B/C vsat=1 卫星集合**：在三方案共同历元上 A vs B、A vs C、B vs C 的
   G/E 集合 100% 相同（相同比例 100.00%，对称差 0 星）→ 定权方式不改变
   共同历元上每历元哪些星相位有效（不据此断言各方案全部统计相同）。

## 3. 事实性观察（不构成结论）

1. 三组开发集**从未出现 tot_v1<4 的历元**（<4 = 0.00%），=4 占 3–17%，
   5–7 占 74–86%，≥8 仅 8–12%；
2. 有效相位星以 5–7 颗为主：对应 E4 中“解 ns≈5–7”的现象，二者口径一致
   （E4a 直接核验共同历元上 tot_v1 = ns，0 例外）；
3. 系统构成因轨迹而异（仅限本三组数据的事实）：
   - 07-14 Xiaomi 与 Samsung：Galileo 单独≥4 的历元占 85–88%，GPS 单独≥4 为 0%；
   - 12-08 Xiaomi：Galileo 与 GPS 单独≥4 各约 23%（相对均衡）；
   - GPS 卫星状态行多（G_n≈5–10）但有效相位少（G_v1≈1.2–3.6），Samsung 有
     12.7% 历元 G_v1=0；
4. A/B/C 在**共同历元**上的相位有效星集合 100% 一致（总历元数略异，见 §2 说明）
   → 定权不改变共同历元上的相位可用星集；后续按系统建模若需跨方案比较应
   限制到共同历元；
5. Galileo“有卫星状态行但 vsat=0”按轨迹占 E 卫星状态行的 9.2%（07-14
   Xiaomi）、18.3%（12-08 Xiaomi）、28.8%（Samsung）——这是 E3 的**理论上限**；
   上限视角（全部变为有效）下 ≥8 历元占比 11→17%、12→31%、8→55%，
   <4 维持 0%。

## 4. E3 决策门槛材料（供决策，不代替实验）

- 潜在增量按轨迹差异大：07-14 Xiaomi 平均 +0.45 星/历元（上限 ≥8：11%→17%），
  增量较小；12-08 Xiaomi +0.67（≥8：12%→31%）；Samsung +1.83（≥8：8%→55%，
  且 ≥5 达 100%），增量最大；
- 但“有卫星状态行但 vsat=0”≠“可恢复为有效相位”：其中包含相位本身缺失或
  bias 状态未建立的行；真正可恢复的比例与精度影响需实验（E3 或逐行 RINEX
  相位存在性核验）才能确定；
- 是否进入 E3 由上述证据 + 后续核验决定，本报告不下结论。

## 5. 局限

- 开发集 3 组，探索性；内部留出集与 Pixel 未参与；
- “有卫星状态行但 vsat=0”的 E3 上限未扣除“无可用相位”的行（未读 RINEX，未实验）；
- 窗口/占比表格以 A 方案自身历元为口径；A/B/C 总历元略异，未声明统计数字
  完全一致（要声明需把全部统计限制到共同历元后重算）；
- `$SAT` 卫星状态行 ≠ RINEX 原始相位观测行，本报告不含逐频观测构成统计。
