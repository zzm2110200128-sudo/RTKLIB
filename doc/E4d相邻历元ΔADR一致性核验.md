## 1. 目的与口径

判断 4c 历元（Samsung 1354 行）所在位置的 ADR 数值上是否与 Doppler 一致，
特别是**进入 4c 历元时能否沿用上一历元 bias**。

口径（修订版）：
- 只读，不修改 PPP；同一卫星、同一频段、相邻历元；弧内相邻间隔 ≤2000 ms，
  不跨时间缺口比较；
- 预测变化 = (rate₁ + rate₂)/2 × Δt；diff = ΔADR − 预测变化；
- **三个统计范围分开报告**：
  1. **主表（入向相邻对）**：t₂ 属于 4c 历元（直接回答"进入 4c 历元"）；
  2. **辅表（双向辅助）**：t₁ 或 t₂ 属于 4c；
  3. **附录（整条含 4c 历元的弧段）**：非 4c 直接结果，仅参考；
- 分组：E1-25（正常对照）、E1-16、E5a-16、E1-其它、E5a-其它；
- 只报分布（对数、Δt、diff 中位/P95/最大、|diff| P95/**最大**、反号对数
  及其中位），**不预设通过阈值**；
- |diff| 前列离群逐例列出，供人工核验。

## 3. 极端离群（|diff| 前列，供逐例核验；本报告不据此下结论）

主表/辅表离群集中在：
- **E5a-16（E31/E13/E07 等）**：单步 |diff| 达 323.0 m（E31 @ utc
  1626296713000：rate −394.6→−394.5 m/s 下 ΔADR 仅 −71.5 m）与 164.9、
  80.2 m 等；E31 相邻两步 rate 由 −394 骤变 −68，需核对伪距率/时间戳；
- **E1-16（E07/E08/E13/E33）**：巨大跳变（243330、107156、82570、61326 m）
  全部出现在**辅表的出向对（t₁ ∈ 4c 而 t₂ ∉ 4c）**，主表入向对没有这些值
  （主表 E1-16 最大仅 69.1 m）；
  **准确含义**：t₁ 是 4c、t₂ 不是 4c 时发生大跳变，说明跳变发生在
  **离开 4c 的下一步**。它**不能否定** t₁ 这个 4c 历元"进入时沿用旧 bias"
  的可能性，只说明 state=16 的数值**随后可能突然失稳**；不能把这些出向跳变
  解读为"直接证明当前 4c 历元不能沿用上一 bias"；
- 上述均为个案材料，未设通过阈值前不做"合格/不合格"判定。

## 4. 事实性观察（诊断，不构成 E3 决策）

1. **对照（E1-25）确认符号/单位约定正确**：主表入向 diff 中位 −0.003 m、
   |diff|P95 0.131 m；
2. **主表（进入 4c 历元）口径下**：E5a-16 入向 diff 中位 −0.106 m、
   |diff|P95 8.144 m（比对照重但非系统性偏离）；E1-16 入向中位 +0.001 m、
   |diff|P95 5.641 m——**E1-16 不再是"中位 2.3 m、P95 266 m"的旧结论**
   （附录口径的旧值主要由弧段内远离 4c 的历元贡献）；
3. **出向（离开 4c 历元）方向存在大跳变（E1-16 尤甚）**：辅表与主表的差异
   提示部分 4c 历元可能位于 ADR 跳变边界或其前一历元——这正是"能否沿用上一
   历元 bias"必须逐例判定的原因；
4. 由于未预设通过阈值，本报告**不写"主体通过/不通过"**，只报告分布与离群；
   恒定半周偏移无法被 ΔADR 检测（会被差分消去），本核验不能排除该类误差。

## 5. 当前可保留的结论（E4d 范围）

- 进入 4c 历元时（主表入向），E1/E5a 的 diff 中位数都接近 0
  （E1-25 −0.003、E1-16 +0.001、E5a-16 −0.106 m）；
- 但 P95 达约 5.6–8.1 m（E1-16 5.641、E5a-16 8.144 m），明显比正常 E1 对照
  （0.131 m）更差；
- 还存在几十至数百米的异常（主表最大：E1-16 69.1 m、E5a-16 323.0 m），
  因此**不能直接认定这些相位安全**；
- **E3 仍不应马上实施**；下一步仅检查主表最大约 10 个离群点，确认是
  ADR 跳变、伪距率异常还是匹配问题，然后对 E3 做阶段性决策，不无限扩展
  诊断。
