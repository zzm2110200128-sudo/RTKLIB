# E5：稳态 IF 码验后残差与 varerr() 名义 σ 的方差匹配诊断（只读）

> 状态：**修订版 v2，待审阅**（未提交；未写入主研究进展；未修改源码/配置/评价脚本；未重跑解算）。
> 日期：2026-09-04；分支：`ppp-varerr-model`。
> 脚本：`util/gsdc2022/analyze_steady_varerr_match.py`
> 运行：`python util\gsdc2022\analyze_steady_varerr_match.py`
> （stdout 含 A/B/C/D 四节；**D 节为每轨迹 × 方案 × G/E × C/N0 档 × 高度角档的完整三维表**，
> C 节为每轨迹 sys×C/N0 折叠表，B 节为跨轨迹合并三维表，A 节为总览。）

## 1. 目的
量化稳态(300+)下 IF(Pc) 码**验后残差**尺度与 varerr() **名义 σ** 的匹配
情况（按系统/C/N0/高度角），只判断模型形状失配方向，为下一次 varerr()
单变量实验提供依据；**不估计真实观测噪声，也不立即生成新参数**。

## 2. 口径（按项目修订版）
- 开发集 3 组；**A/B/C 各自读取自己的 .pos.stat**；共同 Q6 历元 ∩ 各方案
  stat 存在 ∩ 稳态 300+s；**在共同稳态历元上校验三方案 vsat=1 卫星集合
  一致（全部通过，无不一致）**；
- 主分析只保留 **vsat=1 行**：当前未解耦 IFLC 流程下，vsat=1 是“最终保留
  卫星且当前 Pc 已形成”的可靠代理；**不代表全部手机伪距观测**；slip 只作
  描述，不用于筛选；
- 残差 = `$SAT` resp（IF(Pc) 验后码残差，m）；C/N0 为 %.0f 输出值 →
  模型复算称“**按输出 C/N0 的近似复算**”（取整带来的 σ 误差约几个百分点）；
- varerr() 名义 σ（code、frq=0；只用 eratio1=300；EFACT_GPS/GAL=1；
  EFACT_GPS_L5=10 不进入；IFLC ×9 即名义 σ 乘 3）：
  a=0.9、b=0.9(A/C)/0(B)、e=1.5(B/C)/0(A)；
  var_pre9 = a² + b²/sin²el + (errsnr>0 ? e²·10^(0.1·(52−cn0)) : 0)；
  σ_model_i = 3·√var_pre9；
  **注：滤波实际 R = varerr() + 对流层 + 电离层 + 轨道/钟差方差；本诊断只
  研究第一项，未复算完整 R**；
- 分箱：系统(G/E) × C/N0 [20,25)…[45,50)（<20、≥50 单独计数不丢弃） ×
  高度角 [15,30)/[30,50)/[50,90]；n<30 标“样本较少，不作方向判断”；
- 每格（A/B/C/D 各节统一）：n、均值、中位数、样本 std、MADσ
  （=1.4826·median(|r−median(r)|)）、P95|res|、σ_model,RMS=√(mean(σ_i²))、
  比（MADσ/σ_model,RMS）、z_i=res_i/σ_model_i 的 MADσ(z)、P95|z|；
  slip% 全局描述；
- **参数不自带静默硬编码**：启动时解析 data/config/phone_ppp_*.conf
  （stats-eratio1/errphase/errphaseel/snrmax/errsnr/errrcv）、rtklib.h
  （EFACT_GPS/GAL）、ppp.c（IFLC ×9）并校验，与预期不一致即停止报告
  （v2 运行已通过校验）；
- 合并：跨轨迹按“**卫星—历元观测行等权**”（标题即此义，非三轨迹等权）；
  保留每轨迹表；
- 解释边界：比值>1 只写“验后残差尺度大于名义 varerr() 尺度”；仅在零均值、
  白噪声、独立且模型完整等理想条件下才可解释为模型低估。本数据存在验后
  拟合、偏置和时间相关 → **不得**下“低估真实噪声”结论。

## 4. 事实性观察（描述性；严格按解释边界）

> 比值范围按表注明来源（n≥30 的格子）：
> - 每轨迹总览（A 节）：A 0.36–0.40；B/C 0.05–0.07；
> - 合并三维表（B 节）：A 0.16–0.70；B/C 0.05–0.12；
> - 每轨迹完整三维表（D 节）：A 0.04–1.11；B/C 0.03–0.15。

1. **绝大多数格子验后残差尺度 ≤ 名义 varerr() σ**：只能表述为“该批样本的验后
   残差尺度通常小于名义 varerr() 尺度”（验后拟合使残差偏小 + 名义 σ 含保守
   设计；不能解释为模型高估真实噪声）。注意 D 节（每轨迹三维、n≥30）A 个别
   格子比值略 >1（最高约 1.11），故“均不大于”不成立，应说“通常不大于，
   个别细分格子略大于”；
2. **形状方向（A）**：A 的经验 MADσ 随 C/N0 总体呈下降趋势（Galileo 上最
   清楚，如 E：4.98→1.89 m）；该趋势并非在所有轨迹、系统和高度角档内严格
   单调，部分 GPS 与个别档位有回升；固定高度角后的多数分箱仍可观察到该
   方向。而 A 的名义模型没有显式 C/N0 项（σ 由 0.9 m 基项 + 高度角项决定，
   与 C/N0 无关）→ 形状失配方向：A 未显式刻画 C/N0 依赖；
3. **B/C**：errsnr 项经 eratio=300 放大使 IF 码名义 σ 达约 10–140 m
   （σmodRMS 总览 34–58 m），比 A 大一个数量级；验后残差远小于名义 σ
   （比约 0.03–0.15）→ 表现为“码被极重降权”，与既有结论一致；
4. **C ≈ B**：高度角项相对巨大的 C/N0 项影响很小（C 相对 B 的变化很小）；
5. **均值非零且部分格子明显**（如 E [20,25) 均值 ≈2 m、G 个别大值）：残差带
   系统偏置 → 不满足零均值假设，方差匹配解读须谨慎；
6. 边界外（cn0<20、cn0≥50、el 越界）计数均为 0；n<30 格子已标注。

## 5. 可保留的结论与对下一次 varerr() 实验的含义

**可保留结论**：
- B/C 的 errsnr × eratio=300 确实令 IF 码名义 σ 达约 10–140 m，属极重降权；
- C 与 B 非常接近，高度角项相对巨大的 C/N0 项影响很小；
- A 没有显式描述 C/N0 依赖，而经验验后残差总体存在这种形状；
- 但 E1 已证明提高高 C/N0 码的权重会恶化结果 → **E5 不支持继续微调码权重**。

**含义（供设计讨论，不立即实施）**：E5 更支持研究“码只用于初始化/必要辅助”
或转向相位侧，而不是继续调码的 C/N0 权重形状；本结果只提供形状失配方向
的证据，不估计真实噪声，不替代完整时间轴指标。

## 6. 局限

- 只研究 varerr() 第一项，未复算完整 R（对流层/电离层/轨道钟差方差未含）；
- vsat=1 子集为“相位有效条件下的 IF 码残差”，不代表全部手机伪距观测；
- C/N0 为 %.0f 输出值，属“按输出 C/N0 近似复算”（取整误差约几个百分点）；
- 残差为验后、带偏置与时间相关 → 解释严格限于“尺度/形状方向”；
- 合并按卫星—历元观测行等权，非三轨迹等权；每轨迹完整三维表由脚本 stdout
  **D 节**输出（报告仅贴合并 B 节与折叠 C 节代表性结果）；
- 参数校验在脚本启动时执行（conf/rtklib.h/ppp.c），本次运行已通过；
